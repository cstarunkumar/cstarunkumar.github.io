Adding New Notes

To publish an individual note page, simply create a .md file inside the _notes/ directory with front matter: 

---
layout: page
title: Your Note Title
description: Brief overview of this note
category: college # or self-study
course: COURSE_CODE # optional
date: YYYY-MM-DD
---

It will automatically be built by Jekyll and listed on this page!
